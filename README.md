# 市政道路施工封路方案协调与审批平台

源提示词编号：11。支持分段封路范围、施工阶段、绕行路线、车道收窄和临时设施的同一地图协作；检查相邻工程、救护通道、公交覆盖和绕行时延冲突；提供图层开关、路线绘制、阶段时间轴、条件会签、版本比较和公开通告包导出。

## 施工执行交接账（/handoff）

阶段进入执行后，把阶段执行、共用路段、绕行条件和会签接到同一本可续作的账上，规则由纯函数引擎 `src/handoff/engine.ts` 承载（不依赖 Vue，可单测）：

- **路段编号**：端点相同即同一路段，与方向无关；并账只按同一路段编号合并，晚回记录不会整体盖回其他路段或值班室的新调整。
- **现场回传**：记录携带交接单号、现场单号、阶段版本；两边都改同一段时保留现场值为权威值，值班室值登记为冲突待核。
- **级联失效**：任一路段变化，仅令经过该段的后续阶段、公交/急救绕行、以及锚定其上的已接受条件转为「待重算/失效待重算」，其他阶段与条件原样保留。
- **并发提交**：同一交接单先到生效，后到内容整体入待核队列，不改已确认路段。
- **断点续传**：写入失败后按原交接单号从「已确认路段」之后继续，已处理记录重放为 duplicate；交接单关闭后重复提交幂等，不重复关闭、不重复改动。
- **旧方案迁移**：缺路段编号的阶段按路线点生成首版路段，原会签时间与意见原文保留。

`npm test` 运行引擎规则测试（Vitest）。
